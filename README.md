## Things I'm building

### Job Hunt OS

A job-search management application I'm building for myself.

The idea is simple: instead of keeping applications, recruiter conversations, interviews, resumes and follow-ups scattered across different places, everything lives in one application.

The interesting part for me isn't just the CRUD screens — it's designing the workflow behind them.

**Stack:** Angular · TypeScript · Node.js · Express · SQL Server · JWT

**Status:** In development
